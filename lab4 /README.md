# Лабораторная работа №3 — Кластерный анализ экономики городов

**Автор:** Манухин Константин  
**Вариант:** 2 — Экономика городов

## Цель работы

По результатам лабораторных работ № 1–3 необходимо разработать интерактивный дашборд, объединяющий результаты применения трёх методов кластеризации: иерархического кластерного анализа, метода k-средних (k-means) и DBSCAN.

Дашборд должен обеспечивать исследование исходных данных, анализ полученных кластеров, сравнение алгоритмов и оценку качества кластеризации.

## Данные

- **Название города**
- **Среднее рабочих часов** по 12 профессиям
- **Индекс цен** на 112 товаров и услуг
- **Индекс зарплаты** за час работы после вычета налогов

Исходно: 48 городов × 3 числовых признака.

## Ход работы
В ходе работы был создан дашборд с помощью DataLens, который включает в себя:
- Вкладку обзор данных с отображением основных характеристик набора данных.
- 3 вкладки с визуализацией кластеризации методами иерархического кластерного анализа, KMeans, DBSCAN с возможностью переключения параметров, а также более подробного изучения отдельных кластеров и их характеристик.
- Вкладка с выводами и сравнением результатов работы алгоритмов по внутренним метрикам.
